## 根因和修复

1. 旧页面按相邻工具类型分组，而不是按 turnId 分组。现在每轮只留一行可展开的“用时”；最终答复和交付图片/文件放在过程区外。进行中默认展开，完成后自动折叠；失败、中止和无最终答复时不隐藏过程。
2. 后端没有传递最终答复 phase 和轮次时间，前端显示的是每条 item 的耗时。现在历史、SSE、桌面 IPC 三条链路都保留整轮元数据。用时取真实轮次时长或起止时间跨度，不累加并行工具耗时；无时间证据时显示“查看过程”，不编造用时。
3. agentMessage 被直接塞进 pre，Markdown 文件链接变成纯文本。新增不使用 innerHTML 的 DOM Markdown 渲染，并规范化项目内绝对路径、中文/空格和括号路径，提供可点击的文件预览与交付卡片。
4. 图片生成项漏读 savedPath/saved_path/result 路径，工具图片也被藏在折叠区。现在支持这些路径；项目内图片使用既有文件接口，Codex generated_images 下的生成图通过“项目+线程+item+索引”鉴权接口按需读取，不接受客户端任意路径。
5. 文件预览只打开侧栏却未切换到文件标签，原来停在额度标签时看不到正文。现在打开预览会同时切换到文件标签，并支持全屏覆盖。

### 集中复测发现并修复的既有 Windows 持久化问题

单独复核 8 次通过，但并发运行测试文件时再次复现。增加定点持久化诊断后，捕获到 Windows 对 tasks.json.tmp → tasks.json 的原子替换返回 EPERM，导致已创建任务的首消息尚未发送；不是五会话额度断言错误。现仅对 Windows EPERM/EACCES/EBUSY 的文件 rename 进行最多 465 毫秒的有界重试，不重试任务创建或模型发送；Linux 和其他错误直接上抛。新增 4 项确定性测试覆盖成功、瞬时锁定、非重试错误和重试耗尽。原失败及根因日志均保留。

### 测试环境问题（非产品失败）

最终 Windows 全量唯一失败是系统临时盘剩余约 300 MiB，不足以创建 512 MiB 边界文件（ENOSPC）。只移除了本轮已验证的一个明确路径、全零大文件测试样本，保留目录和清理记录；其余文件未批量删除。将大文件测试移到 D 盘、Git 仓库外的独立临时目录后，文件测试 5 通过、1 项平台跳过。中间一次临时目录放在仓库内，导致“非 Git 目录”测试前提不成立；该环境错误同样保留日志并已改用仓库外目录复核通过。
