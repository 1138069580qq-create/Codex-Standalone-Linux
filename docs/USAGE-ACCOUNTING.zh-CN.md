# v1.4 用量统计实施说明

价格及公式参见 README 的 v1.4.0 章节。

## 数据与性能
- attach-only：只观察已连接的后端通知或桌面状态，不启动 Codex、扫描凭据或创建真实测试任务。
- 累计 token 高水位持久化去重；重复通知、重复快照和服务重启不会再次收费。回退/压缩后的不明确历史不自动补算。
- 日汇总按账户、日期、模型、供应商保存；周期完整日期读取汇总，边界日期读取索引日志。全局分母所有账户共用 5 分钟缓存。
- 请求日志按主键游标分页，每页 50 条；趋势最多 366 个时间段；明细接口有独立速率限制。
- 用户 ID 来自经过认证的会话，不接受查询参数指定其他账户。文件和 SSE 在流打开和持续发送期间检查权限。

## 限制
- 不是 Linux 多用户沙箱：网页账户仍使用同一个 OS 用户和同一个 Codex 身份。模型/工具可能按所授权限访问其他路径，切勿将其作为不互信用户的安全租户平台。
- 轮次与时间统计自启用观测后记录；缺失历史不伪造，工具并行区间按墙钟时间去重。
- Codex 的用量通知不是供应商账单；模型或快速档位未回传时只能使用可知信息，页面保留估算标记。
- 不导入 CC Switch 数据库；借鉴其缓存/普通输入/输出分项和累计差值方式，避免读取其他应用凭据。参考其 src-tauri/src/proxy/usage/calculator.rs 与 src-tauri/src/services/session_usage_codex.rs。
