ADMINISTRATION

连接与项目设置

只连接已有 Codex。发现失败不会启动实例；配置保存后需手动连接。不要在此粘贴 token 或密码。

root 必须为 Linux 上已有的绝对路径；不允许目录重叠。grants 中 userId 使用下方账号 ID，权限可选 view / send / approve / files（后三者需同时有 view）。管理员可访问全部项目。

独立账号
